# Hands-on Course Project: Object-Oriented Library System

---

## 🌟 Overview

Welcome to the capstone project for your **C++ Programming Fundamentals** course!

In this comprehensive lab, you'll design and implement an object-oriented library management system that brings together all the concepts you've learned throughout this course. This project will showcase your understanding of **OOP principles**, **memory management**, and **error handling** in C++.

You'll be creating a robust library system that can manage books, patrons, and transactions while implementing:

* Inheritance
* Polymorphism
* Encapsulation
* Modern C++ memory management techniques

As a unique component of this project, you'll also integrate **GenAI tools** for code review to ensure high-quality implementation.

---

## 🎯 Learning Outcomes

By completing this project, you will:

* Design and implement a class hierarchy using **inheritance and polymorphism**
* Apply proper **encapsulation** to protect data integrity
* Implement modern C++ memory management using **smart pointers** and **RAII principles**
* Create a robust error handling system with **custom exceptions**
* Design and implement **unit tests** for key components
* Use **GenAI tools** to review and improve your code
* Document class relationships and technical specifications

---

## 📋 Project Requirements

### Class Hierarchy Design

You'll design a comprehensive class hierarchy for a library management system including:

---

### 📚 Library Items

* **Base class:** `LibraryItem`
* **Derived classes:** `Book`, `Magazine`, `DVD`, etc.
* Each class should include appropriate attributes and behaviors

---

### 👥 Library Users

* **Base class:** `LibraryPatron`
* Different types of patrons with varying borrowing privileges
* User authentication and profile management

---

### 🔄 Library Transactions

* Classes to handle:

  * Checkouts
  * Returns
  * Reservations
* Transaction history and reporting

---

## 🛠 Implementation Requirements

Your implementation must demonstrate:

### 🔹 Inheritance and Polymorphism

Create a well-designed class hierarchy with virtual functions.

### 🔹 Encapsulation

Protect data using appropriate access modifiers and getters/setters.

### 🔹 Memory Management

Use smart pointers (`std::unique_ptr`, `std::shared_ptr`) and follow RAII principles.

### 🔹 Error Handling

Implement a custom exception hierarchy and proper error recovery mechanisms.

### 🔹 Unit Testing

Create comprehensive tests for key components.

### 🔹 GenAI Integration

Use a GenAI tool to review your code and apply meaningful improvements.
